*** What is NodeJS ***
Nodejs is a JavaScript runtime. JavaScript is a programming language used on web browser to manipulate the DOM, to manipulate the page loaded in the browser.
So NodeJS allows us to run JavaScript on a server and also on browsers. so NodeJS can run outside the browser. nodejs uses a v8 engine which is a JavaScript engine built by google . v8 is written in c++
-So NodeJS allows you to run JavaScript on your computer and add extra functionalities to the JavaScript so you can do more useful stuffs.
