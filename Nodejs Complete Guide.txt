*** What is NodeJS ***
Nodejs is a JavaScript runtime. JavaScript is a programming language used on web browser to manipulate the DOM, to manipulate the page loaded in the browser.
So NodeJS allows us to run JavaScript on a server and also on browsers. so NodeJS can run outside the browser. nodejs uses a v8 engine which is a JavaScript engine built by google . v8 is written in c++
-So NodeJS allows you to run JavaScript on your computer and add extra functionalities to the JavaScript so you can do more useful stuffs.

*** Installing Nodejs & Creating the first app ***
-Go to nodejs.org to download and install it
-After installing, type node -v to see if it install successfully on command prompt or powershell

-next you can activate the NodeJS mode on the command prompt by typing node and it will come out with > prompt. This is an interactive mode called rappel TA.
-so with the interactive mode, you can run some NodeJS command and also use it as a calculator.
-To exit the mode, use ctrl d or ctrl c or type .exit

Writing our first NodeJS
-create a folder and open vscode with the folder.
-click on new file + sign  and create a new file (firstapp.js)
-type this: console.log("Welcome to Nodejs");
-go to terminal -> click on new terminal
- on the terminal opened, to run the app type: node firstapp.js

-Writing to a file using the nodejs code
#firstly call the file system function (fs)
const fs = require ('fs');

fs.writeFileSync('hello.txt','Hello world, welcome to nodejs');
then run it on the terminal and it will create a file called hello.txt and content welcome to nodejs)

*** Understanding the roles and usage of Nodejs ***
-They are language or tool runned on the server to handle user request and manage the server resources like database, request, validations etc.
-it is a javascript runtime tool hence it can also run outside the server to execute some operations
-it is a utitlity script and a building tool as well.

-uses of nodejs
*in web development, for creating server and handling incoming request.
*in business logic, handles request, validate input , connect to database
*Handles responses from html or json and the rest.

Alternatives to Nodejs
-python(django), php, Ruby, ASP.NET

-it is fast and efficient.

*** Working with REPL vs Working with File
-R(Read, Read user input), E(eval, evaluate user input), P(Print, print out result), L(Loop, wait for new input)
- to enter REPL, type node in your command prompt or powershell and it will be activated to type your node js commands directly. note, code are not stored in REPL.
-working with file is using apps like vscode and other apps where the code can be stored.
