*** What is NodeJS ***
Nodejs is a JavaScript runtime. JavaScript is a programming language used on web browser to manipulate the DOM, to manipulate the page loaded in the browser.
So NodeJS allows us to run JavaScript on a server and also on browsers. so NodeJS can run outside the browser. nodejs uses a v8 engine which is a JavaScript engine built by google . v8 is written in c++
-So NodeJS allows you to run JavaScript on your computer and add extra functionalities to the JavaScript so you can do more useful stuffs.

*** Understanding Spread and Rest Operators ***
Spread operators works with three dots(...) before the object or before the Array. it is used for copying element on an existing array to the new array.
e.g. const x = [...hobbies]
so it will copy all the elements of hobbies and put it into x and use it has elements in x.
- it works for both objects and arrays.
-Rest operator is the opposite of Spread. You use it when the elements of an object or Array is not defined but you still wan to define the array or object and it comes in arrow function
e.g. const xy =(...args) => {
    return args
  }

//Then calling it 
console.log(xy(1,2,3,4))  // you can input as many element as possible , because the array was defined using Rest opertor.
